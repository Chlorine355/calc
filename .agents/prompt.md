# Задача: Создать MVP игры "Calc" — головоломки на составление максимального выражения

## Контекст
Я делаю казуальную математическую головоломку. Игроку выдается набор чисел и арифметических операторов. Задача — расставить их в правильном порядке, чтобы получить МАКСИМАЛЬНО возможное значение. Идея вдохновлена вирусными рилсами, где стримеры «ломают» калькулятор, получая гигантские числа.

Ключевая фишка: числа растут до абсурдных величин (факториалы, степени степеней), поэтому нужен математический движок, работающий с большими числами.

## Стек технологий (строго соблюдать)
- **Фреймворк:** React 18+ + TypeScript (strict mode)
- **Сборщик:** Vite
- **Стейт-менеджмент:** Effector + effector-react (никакого Redux/Zustand)
- **Стили:** CSS-модули (`.module.css`) — никаких Tailwind/CSS-in-JS
- **Математика:** mathjs (для безопасного парсинга AST и работы с BigNumber)
- **Анимации:** framer-motion
- **Форматирование больших чисел:** кастомный хелпер (научная нотация вида `2.4e543`)

## Система ввода — ГИБРИДНАЯ (КРИТИЧЕСКИ ВАЖНО)

### Проблема
Нужно поддержать три способа ввода:
1. **Клавиатура** (быстро на десктопе)
2. **Клик по кнопкам** (удобно на мобильном)
3. **Drag-and-Drop** (опционально, для тех, кто любит)

### Решение: Курсорная модель
- Выражение — это массив токенов с курсором (как в текстовом редакторе)
- Курсор можно перемещать стрелками ← → или кликом между токенами
- Ввод с клавиатуры добавляет токен в позицию курсора
- Клик по кнопке из "палитры" тоже добавляет в позицию курсора
- DnD работает как дополнение: перетащил токен → курсор переместился за ним

### Частичный ввод и валидация
**НЕ валидируй выражение на лету!** Пользователь должен иметь возможность:
- Ввести `2+` и остановиться (не показывать ошибку "неполное выражение")
- Ввести `2+*3` (синтаксическая ошибка) — показывать красную подсветку, но не блокировать
- Валидация и ошибки **только при нажатии "Вычислить"**

**Визуальная обратная связь:**
- Валидные токены — обычный стиль
- Синтаксически некорректные (например, два оператора подряд) — красная рамка
- Неполное выражение — серый текст "Нажмите Вычислить для проверки"
- Ошибка при вычислении — модальное окно или баннер с текстом ошибки

### Обработка клавиатуры

```ts
// Глобальный обработчик на игровом экране
document.addEventListener('keydown', (e) => {
  if (e.key === 'ArrowLeft') moveCursorLeft()
  if (e.key === 'ArrowRight') moveCursorRight()
  if (e.key === 'Backspace') deleteToken()
  if (e.key >= '0' && e.key <= '9') insertToken({ type: 'number', value: parseInt(e.key) })
  if (['+', '-', '*', '/', '^'].includes(e.key)) insertToken({ type: 'operator', value: e.key })
  if (e.key === '(' || e.key === ')') insertToken({ type: 'parenthesis', value: e.key })
  if (e.key === 'Enter') evaluateExpression()
})
```

## Функциональные требования MVP

### Экран 1: Главное меню
- Кнопка "Играть"
- Отображение текущего уровня и рекорда
- Кнопка "Как играть" (модалка с правилами)

### Экран 2: Игровой экран (основной)
- **Верхняя панель:** номер уровня, очки, кнопка "Сбросить"
- **Центральная зона:**
  - **Поле выражения:** визуализация `$expression` как карточки с мигающим курсором
  - **Палитра:** кнопки с числами и операторами (из `$hand` + `$unlockedOperators`)
  - Клик по кнопке → токен добавляется в позицию курсора
- **Кнопка "Вычислить":**
  - Валидирует выражение
  - Если ошибка → показывает `$validationError`
  - Если ок → вычисляет результат, показывает анимацию, начисляет очки
  - Если результат >= целевого → переход на следующий уровень

### Экран 3: Экран результата
- Показывает собранное выражение
- Показывает итоговое число в научной нотации
- Кнопка "Следующий уровень"
- Кнопка "Поделиться" (копирует в буфер: "Я собрал 10^543 в Calc на уровне 15!")

## Математический движок — КРИТИЧЕСКИ ВАЖНО

### Проблема
JavaScript `Number` переполняется на ~10^308. Нам нужно считать `9^(9^9)` и `100!`.

### Решение
1. Используй `mathjs` с включенным `number: 'BigNumber'`.
2. Преобразуй `$expression` в строку → парси через `math.parse()` → вычисляй через `node.evaluate()`.
3. **Важно:** степень в mathjs правоассоциативна по умолчанию (`2^3^4` = `2^(3^4)` = `2^81`) — это правильно, оставляем так.
4. Для отображения результата напиши хелпер `formatHugeNumber(bn: BigNumber): string`:
   - Если число < 1e6 — показывай как есть
   - Если < 1e1000 — научная нотация `2.4e543`
   - Если больше — показывай как `10^(5.43e100)` (логарифм от логарифма)
5. **Очки** считаются через `log10(result)` — так они растут линейно, а не экспоненциально.

### Валидация выражения (только при вычислении!)
- Проверка на деление на ноль → "Деление на ноль!"
- Проверка на отрицательный аргумент корня/логарифма → "Некорректный аргумент"
- Проверка синтаксиса → "Неполное или некорректное выражение"
- Все ошибки сохраняются в `$validationError` и показываются пользователю

## Генерация уровней

Напиши генератор `generateLevel(level: number)`:
- **Уровни 1-5:** 3 числа из [1..9], операторы [+,*]. Целевое значение растет.
- **Уровни 6-9:** 4 числа, операторы [+, -, *, /].
- **Уровни 10-19:** 4 числа, добавляется '^'.
- **Уровни 20-29:** 5 чисел, добавляется '!'.
- **Уровни 30+:** 5-6 чисел, скобки и конкатенация.

Генератор должен гарантировать, что:
1. Решение существует
2. Есть "оптимальное" решение (не просто тривиальное сложение)
3. Разброс между худшим и лучшим решением — минимум в 10x

Для MVP можно сделать детерминированный генератор (захардкодить 30 уровней вручную).

## Подводные камни, на которые обратить внимание
1. **Не используй `eval()`** — только парсинг через mathjs.
2. **Effector `sample`:** используй его для связи между доменами, не вызывай события напрямую из компонентов.
3. **Курсорная модель:** следи, чтобы курсор не выходил за границы `$expression` (0 <= cursor <= expression.length).
4. **BigNumber в React:** не клади BigNumber напрямую в стор Effector — он должен быть сериализуем. Храни как `{ value: string, exponent: number }` или просто `string`.
5. **Клавиатурные события:** используй `useEffect` с `addEventListener` в компоненте игрового экрана, не забудь `removeEventListener` в cleanup.
6. **CSS-модули:** в Vite они работают из коробки для файлов `*.module.css`. Импортируй как `import styles from './Component.module.css'`.
